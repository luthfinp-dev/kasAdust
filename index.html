Cadangan data

Unduh semua data (transaksi, gaji, aset, tujuan, dan profil) sebagai file .json. Simpan file di tempat aman. File ini bisa diimpor kembali kapan saja, termasuk ke akun lain.

Impor cadangan

Gabungkan menambah data yang belum ada (dicocokkan lewat ID) dan tidak mengubah data yang sudah ada. Ganti semua menghapus data sekarang lalu memakai isi file. Disarankan ekspor cadangan dulu sebelum mengganti.

Reset semua data

Yang akan dihapus:

  • Semua transaksi (riwayat)
  • Gaji tiap bulan
  • Semua aset
  • Semua tujuan beserta sub-item
  • Batas harian
  • Pengaturan sembunyikan saldo

Data tidak bisa dikembalikan. Buat cadangan dulu di Pengaturan, Cadangan data.
